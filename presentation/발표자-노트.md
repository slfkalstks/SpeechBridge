# SpeechBridge 발표자 노트

앱 화면과 핵심 기능 중심의 7장 구성입니다. 설명과 시연을 합쳐 약 5–7분입니다. 실제 앱 캡처에 가상 시연 데이터를 사용합니다.

## 1. SpeechBridge

SpeechBridge는 대화를 번역하고 기록·요약·할 일로 이어주는 앱입니다. Android와 iOS에서 사용할 수 있습니다.

## 2. 음성 입력·번역·읽어주기

언어를 선택하고 마이크로 녹음한 뒤 번역합니다. 한국어·영어·일본어를 지원합니다. 새 번역은 자동으로 읽어줍니다. 자동 읽기는 설정에서 끌 수 있습니다. 오른쪽 화면은 직접 입력한 문장의 번역 결과입니다.

## 3. 대화 기록과 요약

대화는 자동으로 저장됩니다. 대화가 끝나면 AI가 제목을 붙이고 분류와 요약을 정리합니다. 이후에는 사용자가 직접 수정합니다. 일상·업무·업무 폴더로 기록을 찾을 수 있습니다.

## 4. 할 일 관리와 원문 확인

대화에서 찾은 할 일 후보는 원문을 확인한 뒤 등록하고 완료합니다. 할 일에서 원래 기록으로 돌아갈 수 있습니다.

## 5. AI 모델별 역할

Nemotron은 음성 인식, TranslateGemma는 번역, Gemma 4는 기록 정리, Qwen3-TTS는 번역문 음성 합성을 담당합니다.

## 6. 시스템 아키텍처

모바일 앱 ↔ MacBook 서버: Node.js HTTP API ↔ Ollama API / NeMo-Speech.cpp / Python·MLX / PostgreSQL. 회원 인증·음성 인식·번역·음성 합성·할 일 추출·기록 동기화 API.

## 7. 직접 사용해 보기

Demo.command를 실행해 시연을 준비합니다. 보조 키보드로 “please prepare demo slides by friday”를 입력해 번역을 보여주고 대화를 종료해 요약을 확인한 뒤 할 일 근거를 검토합니다. 화면에 나온 내용은 시연용 가상 데이터입니다. 실제 휴대전화·마이크·청취 검증은 보류 중이라 이번에는 텍스트를 입력해 시연합니다.
