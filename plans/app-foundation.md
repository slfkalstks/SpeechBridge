# SpeechBridge 구현 계획

ECC blueprint, 2026-10-17. 설계 원본: ../docs/PRODUCT.md. Git 저장소/remote 없음 → 직접 편집 모드. gh 설치는 확인했으나 GitHub 작업은 없으므로 계정 조회/PR 생성은 하지 않는다.

목표: 번역·기록 독립 선택, 근거 기반 기록 수정과 할 일 관리가 가능한 KMP 앱, 실제 텍스트 API 연결 준비. 음성·실기기 검증은 후속. API 키를 새로 만들거나 유료 호출하지 않는다.

## 의존 관계

S0 설계 검토 → S1 도메인·저장 → S2 공통 UI → S4 통합 검증.
S0 → S3 API 서버·클라이언트 계약 → S4.
S1/S2와 S3 서버 파일은 병렬 가능하지만 이번 실행은 주 에이전트가 순서대로 수행한다. 설계 검토만 별도 검토 에이전트에 위임한다.

## S0 설계 검토 (strongest)

맥락: 기본 KMP 앱은 Android/iOS에서 사용자 실행 확인 완료. 기능은 미구현. docs/PRODUCT.md에 제안/확정/후속 구분.
작업: 상태 규칙, 기록 off 누출, 재번역 경합, 근거/검토, API 인증, 키 없는 상태, 현실적인 테스트를 반대 관점으로 검토. 중대 지적 수정.
검증: reviewer 지적별 조치 기록 docs/DESIGN_REVIEW.md.
종료: 중대 지적 해결, 이번 구현과 후속 구분 명확.
롤백: 문서 수정만 되돌림.

## S1 도메인·저장 (default)

맥락: docs/PRODUCT.md 데이터 규칙. 공유 모델과 로컬 저장, JSON 직렬화 필요. API는 아직 없어도 직접 입력 가능.
작업: models, 순수 상태 변경 규칙, ViewModel, Android/iOS 저장 어댑터. 기록 off 세션 저장 제외. 저장 오류 알림, 삭제, 재시작 복원.
검증: :shared:testAndroidHostTest. 수정 무효화/오래된 응답/저장 필터/완료 검토/삭제 테스트.
종료: 데이터 규칙 테스트 통과, 저장 실패를 성공으로 표시하지 않음.
롤백: 이번 추가 파일과 의존성만 제거. 기존 사용자 파일 보존.

## S2 공통 UI (default)

맥락: S1 상태/이벤트를 UI에서 호출. Android/iOS App 진입점은 기존 것을 유지.
작업: 대화/기록/할 일/설정 화면, 언어와 모드 선택, 발언 수정, 근거 확인, 항목 편집, 완료/삭제. 직접 입력이 기본. 음성 미연결을 명시하고 녹음 UI를 흉내 내지 않음.
검증: Android assembleDebug, iOS compile; 시뮬레이터 렌더링 확인 가능 시 실시. 긴 한국어/일본어·키보드·빈 상태·연결 오류 확인.
종료: 모든 보이는 동작이 실제로 상태를 바꾸거나 명시된 연결 상태를 표시.
롤백: 이전 App.kt 복원, 도메인 데이터 파일은 보존.

## S3 API 연결 준비 (default)

맥락: Azure Translator + Speech token broker, OpenAI Responses 구조화 추출. keys는 server/.env에 사용자가 설정, 앱에는 서버 접속 토큰만 일시 입력.
작업: 서버 핸들러와 주입 가능한 provider, 앱 HTTP 클라이언트, .env.example, 연결 가이드. no keys → 503. 텍스트 번역·정리는 live 코드, 모의 서비스 결과는 테스트에만 사용.
검증: node --test server/*.test.mjs; provider payload·401·503·잘못된 모델 근거·timeout. 클라이언트 응답 버전 검사.
종료: 비밀키 미포함, 계약 테스트 통과, 키 추가 후 검증할 절차 문서화.
롤백: 서버 중지와 앱 연결 해제, 로컬 기록 사용 유지.

## S4 통합·인계 (strongest)

맥락: S1~S3을 합친 첫 앱 기능 구현. 음성 연결과 실측은 완료 주장 금지.
작업: 앱/서버 테스트, Android 빌드, iOS 컴파일. 알려진 제한과 결과 기록. 기존 IDE 빌드 버전은 무관한 업그레이드 없이 유지.
검증: 핵심 시나리오 기록 → 원문 수정 → 재검토 → 할 일 등록 → 완료 → 재시작 → 복원. 번역 전용 대화는 재시작 후 없어야 함.
종료: 실행 가능한 앱 + 검증 결과 + 환경 변수 목록 + 후속 음성 계획.
롤백: 기능별 되돌림. 저장 포맷 버전으로 모르는 버전은 덮어쓰지 않고 오류 표시.

## 계획 변경 규칙

새 실패/사용자 변경이 있으면 상태·의존성을 이 파일에 기록한다. 기능을 조용히 제외하거나 완료로 바꾸지 않는다. 검증 불가능한 항목은 미검증으로 인계한다.

## 실행 기록

- S0: 별도 검토 완료. R1–R8 반영; docs/DESIGN_REVIEW.md 참조.
- S1~S3: 첫 기능 구현 및 API 연결 준비 완료.
- S4: 자동 검사·Android 기록/복원/서버 상태·iOS 전체 빌드/시작 확인 완료. 미검증 범위는 docs/VALIDATION.md 참조.
- 사용자 추가 결정: 휴대전화 LLM 추론 대신 서버 중심 AI. 자체 서버 모델은 성능 비교 후 도입 후보. docs/AI_STRATEGY.md.
