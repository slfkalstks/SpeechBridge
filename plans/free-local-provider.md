# 무료 Mac provider 연결 계획

2026-10-17. 기존 blueprint의 S3를 무료 정책으로 교체하는 후속 구현. 직접 편집 모드. 설계 근거는 docs/FREE_AI_RESEARCH.md. 유료 API·클라우드 모델·새 계정 없이 현재 Mac에서 실행한다.

## 범위와 의존성

F0 설계 검토 → F1 로컬 provider·계약 테스트 → F2 실제 모델 검증 → F3 앱 연결·상태/오류 개선 → F4 문서·인계.

- F0: 로컬 전용 경계, 문맥 초과, 요청 취소, 구조화 출력의 근거 검사, 메모리 경쟁 검토.
- F1: Ollama 전용 localhost HTTP 어댑터. 승인된 로컬 모델 이름만 사용하고 remote/cloud 모델·redirect 금지. 다운로드는 개발 준비 명령에서만 수행하고 사용자 API 요청에서 자동 다운로드하지 않는다. translation/extraction 설정과 실제 모델 가용성을 구분한다.
- F2: 번역 TranslateGemma12B, 추출 Gemma4 12B QAT. 이미 설치된 Qwen3.5-9B-Q8도 비교할 수 있다. 모델은 프로젝트의 무시되는 .runtime 아래 저장. Ollama 별도 포트11435, cloud 비활성, 최대 상주1·parallel1로 시작. 텍스트 여섯 방향·정정/취소/근거 fixtures로 확인하고 결과를 기록. 공개 후보와 실제 측정 결과를 혼동하지 않는다.
- F3: 앱에서 과금·외부 상용 API를 전제로 한 문구를 수정. 대기/실패/취소가 원문을 보존하는지 확인. 시뮬레이터의 실제 번역·추출→검토→할 일 확인. UI 대규모 재설계와 음성 모델 전체 도입은 별도 단계이며 완료로 표시하지 않는다.
- F4: 현재 실행 절차, 모델 digest·실측·남은 문제, 중단 방법을 문서화. 이전 유료 안내는 현행 절차로 되살리지 않는다.

## 불변 규칙

- 휴대전화에 AI 모델을 설치하지 않는다. Mac 추론 런타임은 루프백에만 바인딩한다.
- 앱의 종료·수정·취소·연결 종료는 더 이상 필요 없는 모델 요청을 중단한다. 서버는 대기열을 무한히 쌓지 않는다.
- 번역 원문을 문장 단위로 나눌 수 있으나 누락·잘린 출력을 성공으로 반환하지 않는다. 모델 context와 생성 길이를 제한하고 overflow/timeout은 명시적으로 실패한다.
- 추출에는 원문 ID/revision과 정확한 인용문이 필요하다. ID·revision·인용문 포함 여부를 서버에서 검증하며 없는 담당자/기한은 null. 이 검사는 의미의 정확도까지 보장하지 않으므로 사용자 검토 유지.
- 대화 본문을 런타임/앱 로그에 남기지 않는다. 검증 fixtures는 가상 데이터만 사용한다.
- 기존 기록과 사용자의 Ollama 설정/모델을 삭제·수정하지 않는다. 실패 시 미연결 상태로 되돌릴 수 있다.

## 검증과 종료 조건

서버: node --test server/*.test.mjs. 유료/원격 모델 차단, 미설치·offline 상태, truncation, 근거 조작, 취소·timeout·큐 한계 검증.
실측: 가상 번역6방향·추출의 요청/거절/취소/근거 검사. warm/cold와 실제 elapsed를 구분하며 작은 fixture 결과를 일반 정확도라고 표현하지 않는다.
앱: 공통 테스트·Android 빌드·iOS compile, 영향 있는 UI/네트워크 흐름 확인. 실제 음성·실기기는 미검증 상태 유지.
종료: 실제 무료 텍스트 모델 연결, 재현 가능한 실행법, 검증 증거. 외부 설치/모델 다운로드가 막히면 원인과 완료 범위를 명시하며 연결 성공을 가장하지 않는다.

## 롤백

프로젝트 런타임 프로세스만 중단하고 AI_PROVIDER=disabled로 전환하면 직접 입력·저장·수동 할 일을 유지한다. 모델 파일과 사용자의 기존 기록은 자동 삭제하지 않는다.
