# 대화 중심 리디자인

2026-10-17 사용자 지시가 기존 nonvoice-completion의 시작 폼·기록 선택 정책을 대체한다.

- [x] 사용자 범위 확정: 음성 자동 감지/연결은 UI만, 실제 기능·실기기는 보류. 업무는 고정 분류 + 사용자 폴더.
- [x] 참고 조사: 파파고 App Store 스크린샷, Google 공식 대화 화면, Apple 녹음 폴더 안내, Notta 공식 앱 화면. Mobbin 공개 라이브러리 확인.
- [x] 대화 시작 제목/모드 제거, 항상 저장, 언어 선택 축약, 음성 중심 UI·보조 키보드 입력.
- [x] 종료 후 무료 로컬 AI 제목·일상/업무·업무 유형/기존 폴더 추론, 실패/재시도/수동 수정, 기존 데이터 호환.
- [x] 기록/할 일 공통 분류 필터, 사용자 폴더 생성/이름 변경/삭제(기록 유지).
- [x] 3개 기본 탭, 설정 진입 분리, 목록/발언 동작 더보기로 축약.
- [x] 의미 있는 회귀 테스트, 양 플랫폼 빌드, 실제 AI·시뮬레이터 검증, 결과와 한계 기록.

사용자 추가 지시: 대화는 음성 중심. 마이크/음성 대화를 주 화면으로 두고 키보드는 보조 진입. 음성 기능 자체는 앞선 답변대로 추후 구현.

검증 범위와 잔여 한계는 docs/REDESIGN_VALIDATION.md에 명시. Android 전체 클릭/스크린리더/실기기는 완료로 표현하지 않는다.
