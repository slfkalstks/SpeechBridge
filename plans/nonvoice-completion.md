## 범위

1. IDE 경로: 실제 SpeechBridge 루트와 사전 검사 확인. **완료**: Android Studio 화면에서 OS/Java/Android SDK/Xcode/Gradle 모두 ✓ 확인.
2. UI/UX: 현재 동작하는 초기 시제품을 공통 디자인/행동 계약에 맞춰 개선. 대화/정리 분리, 입력 접근, 검색/필터, 오류·삭제·초안 보존, 작은 화면/태블릿/큰 글자/키보드/접근성 확인.
3. 텍스트 AI: 더 다양한/긴 가상 대화, 정정·취소·근거 검사, 반복 지연·모델 전환·메모리 측정. 실패 원자료 보존, 발견한 재현 가능한 결함 수정. 일반 정확도 보장으로 표현하지 않음.
4. Android/iOS: 공통 테스트 및 빌드, 실제 텍스트 API UI, 작성·수정·검토·할 일·재시작 복원·기록 off 확인. 기존 사용자 기록 보존.
5. 문서: 현재 구현과 과거 문서 불일치 정정, 실제 증거/실행법/잔여 검증 기록.

## 제외 및 확인 한계

음성 V3/V4, STT/TTS 변경·품질·성능, 실제 마이크/휴대전화·LAN HTTPS·외부 배포는 이번 실행에서 다루지 않는다. 사용자 실기기 보류 응답(2026-10-17)을 따른다. 모델/기록/토큰을 보존하며 모든 작업은 이 앱 폴더 안에서 한다. 시뮬레이터 검증을 실기기 검증으로 표시하지 않는다.
