# 직접 앱 시연 검증

2026-10-19 작성. 사용자의 “직접 시연한다고 생각하고 앱 테스트” 요청에 따라 iPhone 17 Pro / iOS 26.5 시뮬레이터의 앱을 직접 조작했다. Mac의 실제 로컬 AI 모델·회원 API·LAN HTTPS·PostgreSQL을 사용했다. 실제 휴대전화나 마이크 녹음 검증을 대신하지 않는다.

## 확인한 흐름

| 항목 | 직접 관찰한 결과 |
|---|---|
| 언어 맞바꾸기 | 한국어→영어를 영어→한국어로 그대로 전환. 일본어 선택·한국어 재선택도 반영 |
| 실제 번역 | `please prepare demo slides by friday`를 입력·기록하자 `금요일까지 데모 발표 자료를 준비해 주시기 바랍니다.` 생성 |
| 종료·자동 정리 | 종료 확인 후 처리 중 표시 → `Demo Slides Preparation` 제목, 업무·할 일 분류, `금요일까지 데모 슬라이드를 준비해달라는 요청이 있었다.` 요약 |
| 할 일 | AI 추출 → 원문 근거 확인 → 내용 확인 완료 → 할 일 등록 → 완료 체크 → 완료 필터에 해당 항목만 표시 |
| 기록 필터 | 일상 선택 시 주말 약속, 업무 선택 시 업무 기록, 시연 프로젝트 폴더 선택 시 해당 기록만 표시 |
| 수동 편집 | AI 제목을 `demo reviewed`로 변경하고 시연 프로젝트 폴더 지정. 재실행 후 그대로 유지 |
| 화면 모드 | 가로 아이콘으로 다크·라이트·기기 설정 각각 적용. 다크 상태로 앱 재실행 후 유지 확인, 마지막에는 기기 설정으로 복원 |
| 계정 복원 | 앱 종료·재실행 후 시연 로그인과 4개 기록 복원 |
| 연결 장애 | 이 프로젝트 HTTPS 프록시만 중단 → 라이트 모드 변경 → `1건 전송 대기` 표시 → 프록시 복구 후 버튼 조작 없이 `서버 저장 완료` |
| 계정 삭제 취소 | 확인창의 삭제 범위·백업 안내·비밀번호 입력·확정 비활성 확인. 취소 후 계정/4개 기록 보존 |
| 권한 거절·알림 | 마이크 요청에서 허용 안 함 → 마이크 설정 안내 표시 → 닫기 조작 없이 자동으로 사라짐. 녹음은 시작하지 않음 |

UI 검사 후 같은 시연 회원의 서버 스냅샷을 읽어 기록 4개, 실제 번역·요약, 수동 제목/폴더, 검토 완료된 DONE 항목, SYSTEM 화면 모드를 assert로 재확인했다. 로그인을 위해 발급한 검사 세션은 로그아웃했다. 상세 결과 `.runtime/demo/ui-validation.json`, 화면 캡처 `.runtime/demo/ui-home.png`, `.runtime/demo/ui-summary.png`는 로컬 전용이다.

## 시연을 위해 남긴 상태

Mac API와 HTTPS·PostgreSQL·로컬 AI를 실행 상태로 유지했다. 시뮬레이터는 시연 계정에 로그인되어 있고, 한국어↔영어 대화 시작 화면이다. 마이크 거절 검증 후 **이 앱의** 권한만 초기화했으므로 다음 사용 때 권한을 다시 선택한다. 시연 예시 3개와 이번에 만든 `demo reviewed` 기록 1개를 보존했다. 이전 기기 기록 4개와 폴더는 가져오거나 지우지 않았다.

## 이번 검증의 한계

실제 녹음·발화 자동 언어 감지·스피커 청취, 물리 Android/iPhone, VoiceOver/TalkBack 전체 접근성, 스토어용 Release·서명은 이번 직접 UI 검사의 대상이 아니다. 음성은 별도의 합성 샘플 검증과 실사용 검증을 구분한다. 계정 영구 삭제 성공은 테스트 DB의 자동 검사로 검증했으며 시연 회원을 UI로 삭제하지 않았다. 로그인 복원을 확인했지만 이번 UI 순서에서 새 회원가입이나 비밀번호 재설정은 검사하지 않았다.

이번에 확인한 흐름에서는 진행을 막는 오류를 발견하지 않았다. 이를 앱의 모든 기능·환경에 대한 무결점 보장이나 배포 준비 완료로 해석하지 않는다.
