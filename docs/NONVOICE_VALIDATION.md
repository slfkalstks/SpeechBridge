# 음성 제외 개선·검증

2026-10-17. 사용자 요청에 따라 음성 연결·관련 구현을 제외했다. 실기기 검증은 계속 보류한다. 모든 입력은 가상 테스트 문장이고 유료 API는 사용하지 않았다.

## 현재 제품 단계

실제 저장·번역·정리·근거 검토가 동작하는 **사용성 개선 시제품**이다. 이전의 기능 중심 초기 UI에서 대화/정리 탭, 공통 색상·타이포그래피, 기록 검색, 할 일 필터, 초안 보존, 오류·확인 흐름을 보완했다. 실제 사용자 사용성 평가나 배포 제품 수준의 접근성 적합성을 입증한 것은 아니다.

## 구현·수정

- 공통 Compose 테마와 탐색 아이콘, 모바일 하단 탐색/넓은 화면 rail. 넓은 원문·번역은 나란히 배치. 시작·연결 폼은760dp 안에 중앙 정렬. 작은 높이의 대화 머리말은 스크롤 가능.
- 대화/정리 분리, 고정 입력 진입 버튼, 별도 입력 폼. 시작/발언/연결 초안은 현재 실행 메모리에 유지하고 기록 파일에는 넣지 않는다. 편집 중 닫기는 변경 폐기를 확인한다.
- 기록 제목·원문·번역 검색, 할 일 내용·담당·기한 검색 및 검토/진행/완료 필터. IME 조합 중에는 검색을 확정하지 않는다. 원문 수정으로 검토가 필요해진 완료 항목은 완료 필터에서 제외한다.
- 개별 요청 실패·취소 원인을 해당 항목에 보존하고 재시도 시 해제. 접속 토큰 누락을 구체적으로 안내. 설정 오류 필드에 포커스. 삭제는 이름/영향을 보여 주는 확인창 사용.
- AI 정리의 응답 언어를 세션 첫 언어로 전달(기존 기본 한국어 고정 문제 수정).
- 번역의 부정/수치/상대 시간 보존, 정리의 명시 담당·기한 및 금지 조건 보존 지시 보완. 추측으로 메타데이터를 채우는 코드는 추가하지 않았다.
- iOS 입력에서 화면 상태를 즉시 갱신하면서 ViewModel 초안을 함께 갱신하도록 보강. 이후 가상 영문 문장이 누락 없이 입력되는 것을 확인했다. 자동화 도구의 붙여넣기/키보드 언어 전환 문제도 있었으므로 모든 입력 이상을 앱 결함으로 단정하지 않는다.

Android/iOS 각28개에는 템플릿 검사2개가 포함된다. 공통26개 + 플랫폼 템플릿1개 + 플랫폼별1개(결과상 각28개)이며, 플랫폼별 새 검사는 Android 로컬 시간대 날짜 경계/iOS 실제 파일 저장이다. 두 플랫폼의 공통 검사를 서로 다른56개 기능 검사로 합산하지 않는다.

추가 검사: 초안/토큰 저장 제외, 종료·입력 확정 시 초안 제거, 정리 언어 전달, 취소 오류 보존 및 재시도, 검색/재검토 필터, UTC 날짜 경계. 기존 검사에는 기록 off, 오래된 응답 무시, 수정 후 근거 무효화, 저장 실패·재시도·손상 보호가 포함된다.

정적 audit는 웹 소스 중심이므로 Kotlin 네이티브 의미·터치·포커스를 전부 검사하지 않는다. 색 대비 검사도 명시한 텍스트 색 조합에 한정한다. VoiceOver/TalkBack 청취·전체 키보드 포커스 순서·접근성 인증의 증거로 사용하지 않는다.

## 직접 확인한 화면

iPhone17Pro/iOS26.5 Simulator에서 새 UI의 실제 텍스트 API 흐름:

1. URL/짧은 토큰 입력 오류, 적용 전 상태 확인 비활성화, 마스킹, health 준비 상태 확인.
2. `qa20261017` 가상 대화, English→한국어. `Mina please send the draft by tuesday` 입력, 닫기·연결 화면 이동 후 초안 유지.
3. 실제 번역 `미나 씨, 초안을 화요일까지 보내주세요.` 표시.
4. 실제 정리 `send the draft`, 담당Mina/기한tuesday → 원문·인용문 근거 확인 → 검토 완료 → 할 일 등록 → 완료.
5. 완료 필터에 표시, 검토 필요 필터는0개와 빈 결과 안내. 기록 검색 `nomatch`는0개, 초기화하면3개의 가상 기록 복원.
6. 앱 프로세스 종료/재실행 후 완료 상태·기록 복원, 연결 토큰은 초기화. 재번역 시 토큰 입력 안내와 기존 원문 유지.
7. 원문 끝에 마침표 추가 후 기존 번역 무효화, 완료했던 항목이 검토 필요로 전환되고 상태 변경 버튼 비활성화.
8. 글자 크기 large에서 extra-extra-large까지 두 단계 늘린 환경에서 기록/할 일 화면과 줄바꿈 확인. 검증 후large로 복원. 최대 접근성 글자 크기 전 구간 검증은 아니다.

iPad Pro11(M5) Simulator의 세로 시작 화면, 가로 rail, 최종760dp 중앙 폼을 화면으로 확인했다. iPhone 최종 가로 화면에서도 rail·제목·탭·본문 배치를 확인했다. 이 자동화 환경에서 가로 본문의 스크롤 입력은 결과를 확인하지 못했으므로 전체 가로 화면 조작성 통과로 기록하지 않는다. Android API35 에뮬레이터에 최종 APK를 업데이트했고 새 시작 화면의 배치와 한국어/영어/일본어 라벨을 확인했다. Android 실제 모델 전체 흐름은 이전 `VALIDATION.md`의 QA-local-AI 증거이며, 이번 새 UI의 전체 Android 클릭 흐름을 다시 확인한 것으로 확대하지 않는다.

사용자 기록을 삭제하지 않았다. iOS의 검증 대화3개는 남겨 두었다(키보드 입력 실험으로 생성된 빈 대화2개 포함). 영구 삭제는 확인창 구현·도메인 테스트로 검사했으며 사용자의 실제 데이터 삭제를 실행하지 않았다.

## 실제 텍스트 모델 평가

재현: Mac에서 `sh server/start-ai.sh` 실행 후 `node server/evaluate-text-suite.mjs`. 임시 인증 HTTP 서버를 내부에서 열고 종료한다. 원자료 [초기 결과](validation/text-suite-baseline.json), [보완 후 결과](validation/text-suite.json). 모델 digest·provider 해시·합성 원문/원응답 포함. 실사용 기록/접속 토큰은 포함하지 않는다.

TranslateGemma12B/Gemma4 12B QAT, 한·영·일6방향 번역, 동일 번역5회, 정정/담당 변경/취소/미확정 제안/금지/일본어/인용 명령/14발언 대화 정리8종, 모델 전환,5동시 요청을 실행했다.

| 관찰 | 결과 |
|---|---|
| 상대 시간 |초기 ko→en의 ‘다음’ 누락이 보완 후 `next Tuesday`로 보존됨|
| 근거 메타데이터 |정정 기한, 새 담당자, 영어·일본어 담당/기한 필드가 보완 후 반환됨|
| 금지 조건 |일본어 정리에서 빠졌던 ‘고객명 변경 금지’가 보완 후 포함됨|
| 취소/미확정/인용 |취소된 예약 대신 확인 요청만 유지, 미확정 제안·인용문 속 지시는 빈 목록|
|14발언 |앞12개 진행 공유에서 요청을 만들지 않고 마지막 요청/결정2개 반환|
|남은 의미 오류 |en→ko가 원문에 없는 ‘제출된 초안’을 반환. 동시 번역 한 건의 `please`가 ‘제발’로 어색하게 표현됨|

보완은 같은 입력에 대한 재평가여서 독립 평가나 일반 정확도 수치가 아니다. 한 개 근거 발언에 없는 담당/기한은null일 수 있으며 문맥에 있더라도 자동 추측으로 확정하지 않는다.14발언을 장시간 회의 검증으로 부르지 않는다.

보완 후 HTTP 지연:6방향2.120–2.619초, 같은 짧은 번역5회0.577–0.962초(중앙값0.590초), 정리8종1.380–7.487초, 정리 모델에서 번역으로 전환5.362초.5동시 호출은200×4+429×1, 전체4.265초. 단일 추론+대기3개 운영 설정 결과이며 다중 사용자 서비스 성능 보장이 아니다.

1초 간격으로 Ollama 프로세스 RSS를 합산한 최대 관측값은9,867,411,456바이트(약9.19GiB). 공유 페이지 중복 가능, GPU 전용 사용량·시스템 전체 메모리·실제 순간 최대와 구분한다. 마지막 `/api/ps`의 번역 모델 size_vram은8,072,105,819바이트. 초기 평가의RSS0은권한 문제로 측정 실패했으므로 메모리0사용으로 해석하지 않는다.

## 남은 검증과 보류

실기기·마이크·음성 연결·LAN HTTPS·외부 배포는 사용자 지시에 따라 보류한다. 최종 사용자 평가, VoiceOver/TalkBack 청취, 최대 글자 크기 전 구간, 모든 화면의 양 플랫폼 키보드/회전 조합은 완료하지 않았다. 모델 의미 오류도 남아 있다. 이를 ‘모든 상황 검증 완료’나 상용 배포 준비 완료로 표시하지 않는다.
