# 음성 미리보기와 녹음 길이

대화 화면에서 인식 원문과 번역문을 따로 확인할 수 있습니다. Android AudioRecord와 iOS AVAudioEngine은 녹음 중 약 3초마다 누적 PCM을 제공하고, 서버가 인식·번역한 결과를 미리보기에 반영합니다. 연속 토큰 스트리밍이 아니라 짧은 간격의 요청 방식이며, 실제 갱신 시점은 음성 길이·언어 감지·서버 처리 시간에 따라 달라집니다.

- 한국어 ↔ 영어에서 일본어가 감지되면 일본어 → 영어로 표시합니다. 번역 대상이 말하면 입력·번역 방향을 바꿉니다.
- 오른쪽 번역 언어를 한국어로 바꾸면 원문과 녹음을 유지하고 다시 번역합니다. 이전 대상 언어로 요청했던 응답은 적용하지 않습니다.
- 중간 인식은 수정될 수 있습니다. 미리보기는 영구 기록이나 TTS 재생을 만들지 않으며, 완료 후 최종 결과만 한 번 저장합니다.
- 미리보기 실패는 녹음을 취소하지 않습니다. 최종 전체 음성으로 다시 처리합니다. 화면 이탈·취소 시 늦은 응답을 버립니다.
- 녹음 길이는 `5초`, `2분 15초`, `1시간 3분 20초`로 표시합니다. PCM 길이를 밀리초로 저장하고 표시할 때 초 단위로 올림합니다. 대화의 길이는 음성 입력들의 합계이며 대기·번역 시간은 제외합니다. 한 번의 입력은 기존처럼 최대 30초입니다. 길이가 없는 옛 기록과 텍스트 입력에 가짜 값을 채우지 않습니다.

## 검증

서버 테스트 110개, Android host 123개, iOS simulator 130개 통과. 실제 마이크·휴대전화·스피커 청취는 보류했습니다. iOS의 16/44.1/48 kHz 스테레오 합성 버퍼를 16 kHz 모노로 변환하는 네이티브 테스트를 포함합니다.

`cd server && node evaluate-live-preview.mjs`는 프로젝트 테스트 DB와 실제 로컬 모델로 합성 음성을 검사합니다. 결과는 [원자료](../server/validation/live-preview.json)에 있습니다. 이번 3초 구간은 영어에서 미리보기 성공, 한국어·일본어에서는 언어 감지 미확정으로 처리되지 않았습니다. 전체 합성 음성 3개는 모두 인식·번역했고, 일본어 원문을 유지한 영어→한국어 재번역 및 녹음 길이 DB 왕복 저장도 확인했습니다. 이는 실제 마이크 성능 검증이 아닙니다.

구현 참고: Apple [AVAudioNode tap](https://developer.apple.com/documentation/avfaudio/avaudionode/installtap(onbus:buffersize:format:block:)), [AVAudioConverter](https://developer.apple.com/documentation/avfaudio/avaudioconverter).

시뮬레이터 직접 확인: 대화 첫 화면의 원문/번역 영역, 기록 목록·상세의 `5초`, 발언 옆 `5초`를 확인했습니다. `[시연] 일정 전달`은 4,560 ms 합성 영어 음성과 실제 인식·번역 결과를 사용한 추가 시연 기록입니다. 기존 기록은 변경하지 않았습니다. 발표자료와 README의 대화·기록·번역 캡처를 갱신했습니다.
