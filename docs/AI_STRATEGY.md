# AI 처리 위치와 무료 모델 선택

2026-10-17. 사용자 결정: **휴대전화가 아닌 서버에서 AI 처리, 유료 사용 금지, 현재 Mac만 사용 가능.** 실제 장비는 M3 Max·36GiB다.

현재 방침은 Mac 자체 모델을 기본 후보로 검증하고, 정식 무료 API를 동일 입력의 비교군으로 사용하는 것이다. 후보·라이선스·무료 한도·공식 출처·남은 불확실성은 [FREE_AI_RESEARCH.md](FREE_AI_RESEARCH.md)를 기준으로 한다.

## 구성과 검증 상태

- STT: Nemotron3.5 Streaming0.6B + NVIDIA NeMo-Speech.cpp Metal.
- 번역: TranslateGemma12B.4B 및 범용 모델 통합 경로도 비교.
- 추출: Gemma4 12B QAT. Qwen3.5/3.8과 비교.
- TTS: Qwen3-TTS0.6B MLX. CPU 경량/음질 대안도 비교.
- 실행: 네이티브 Mac 런타임, 번역 우선·추출 낮은 우선순위. 모든 모델 동시 상주 가능 여부는 미측정.

텍스트 모델 다운로드·로컬 provider 연결·실제 추론을 완료했다. 기본 번역은TranslateGemma12B, 추출은Gemma4 12B QAT이며4B/Qwen 비교 결과는 [LOCAL_AI_RESULTS.md](LOCAL_AI_RESULTS.md)에 있다. 음성·학습·무료 외부 API 비교는 아직 수행하지 않았다. 모든 후보 중 최상이라는 결론이나 실시간 통역 달성 주장이 아니다. 유료 호출 코드는 없다.

## 교체 경계와 정확도

KMP의 TextTranslator/ActionExtractor와 서버 provider 경계를 유지한다. 음성 입력·출력 계약은 실제 스트리밍 서버에 맞춰 후속 연결한다. 사용자 폰에 큰 모델을 다운로드하지 않는다.

번역/기록 설정을 독립적으로 유지한다. 원문 revision에 맞는 결과만 반영하고, 원문 수정은 연결된 항목을 재검토로 돌린다. 모델은 초안을 만들며 할 일 확정은 사용자가 한다. JSON 형식 준수는 사실 정확도 보증이 아니다. 담당자·기한·부정·취소·수치의 의미와 근거를 별도로 검사한다.

## 평가 순서

1. 여섯 번역 방향과 세 언어 추출을 같은 정답 자료로 비교한다.
2. 공개 음성으로 STT 정확도와 TTS 발음을 평가한다. 실제 실기기 음성 검증은 이후 진행한다.
3. cold/warm, p50/p95, 메모리·swap, 동시 번역/정리 부하와 실패율을 측정한다.
4. 무료 계정 조건이 확인된 API만 비교한다. 무료량 종료 시 유료 대체 없이 실패/재시도 또는 검증된 Mac 경로로 처리한다.
5. 반복되는 도메인 오류와 사람이 검증한 데이터가 확보된 뒤에만 미세조정을 검토한다. 처음부터 학습하거나 큰 모델을 쓰면 무조건 좋아진다고 가정하지 않는다.

실제 API·모델의 활성 상태는 [API_SETUP.md](API_SETUP.md), 완료한 검사는 [VALIDATION.md](VALIDATION.md)를 따른다.
