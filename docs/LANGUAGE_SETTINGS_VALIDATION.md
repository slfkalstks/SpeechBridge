# 언어·설정·대화 요약 검증

검증일: 2026-10-17~18. Android/iOS 시뮬레이터 및 Mac 로컬 모델 기준이며 실제 마이크·휴대전화 검증은 보류했다.

## 변경

- 언어 바 전체를 누르면 설정창만 열리던 문제를 좌우 언어 버튼과 독립 교환 버튼으로 분리했다. 각 언어는 선택 즉시 적용한다. 반대편 언어 선택은 쌍 교환으로 처리한다.
- 입력 초안은 상단 입력 언어와 동기화하고 텍스트는 유지한다. 쌍 순서만 바뀌면 기존 번역과 요청을 유지한다. 실제 번역 대상이 바뀔 때만 이전 요청을 무효화하고 재번역한다.
- 화자 입력·이름 표시를 제거했다. 저장 파일의 speaker는 기존 기록 호환용으로 보존하며 새로운 UI 입력의 화자 값은 비어 있다. 화자 추론을 추가하지 않았다.
- 설정은 톱니바퀴 아이콘이다. 화면 모드는 기기/라이트/다크를 아이콘으로 순환하며 기기에 저장한다. 설정의 언어 항목은 제거했다.
- 일반 설정에는 모드·업무 폴더·저장 상태만 있다. 개발 연결은 Debug 빌드의 더보기 메뉴에 분리했다. Android는 debuggable 플래그, iOS는 Native debug binary 값으로 제어한다.
- Release AI 클라이언트는 배포 서비스 준비 전 상태를 반환한다. 사용자에게 localhost나 개발 토큰을 입력하도록 요구하지 않는다. 실제 운영 서버·사용자 인증·자동 서비스 연결을 완성한 것은 아니다.
- 알림은 Material Short 시간 후 닫힌다. 접근성 권장 시간은 프레임워크가 반영하며, 복구가 필요한 오류는 해당 항목에 남는다.
- 종료 시 제목·분류·요약을 한 번 요청하고 시도 여부를 저장한다. 이후 직접 편집한다. 재생성 메뉴와 초기 생성 재시도는 없다. 할 일 추출은 별도 기존 기능이다.
- 원문 변경·수동 편집과 경합한 AI 결과를 거부하고 기존 기록을 소급 재생성하지 않는다.

## 조사 근거

[Google 번역 공식 음성 번역 안내](https://support.google.com/translate/answer/6142468/?co=GENIE.Platform%3DAndroid&hl=en)는 입력/번역 언어를 각각 선택하는 흐름을 설명한다. 이를 참고해 두 언어를 하나의 적용 폼으로 묶었던 앱 동선을 분리했다. 가운데 아이콘의 문제는 실제 Compose 코드에서 아이콘 자체의 onClick이 없음을 확인했다.

요약 응답의 필수 필드 누락을 확인한 후 [Ollama 구조화 출력 문서](https://docs.ollama.com/capabilities/structured-outputs)에 따라 /organize에 JSON schema를 적용했다. [Kotlin isDebugBinary](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.native/-platform/is-debug-binary.html)를 iOS 개발자 메뉴 조건으로 사용했다.

Kotlin 수에는 기존 템플릿 검사도 포함한다. 추가 검사는 언어 교환·초안 보존·번역 대상 변경 후 늦은 응답 거부·화자 미지정·요약 저장·AI 중복 실행 방지·수동 편집 우선·원문 변경 경합·테마 저장/기존 데이터 호환·배포용 연결 경계를 검증한다. 집계는 [검사 결과 JSON](validation/language-settings-tests.json)에 남긴다.

Release framework에는 기존 bundle ID 추론 경고가 남는다. 배포 서명이나 스토어 업로드 검증을 뜻하지 않는다.

## 실제 Mac 모델 평가

Gemma4 12B IT QAT, 무료 로컬 추론, 가상 대화 7개. [최종 결과](../server/validation/summary-suite.json).

초기에는 취소된 배포 일정 사례에서 title 필드 이름이 누락돼 응답 검증이 거부했다. [보강 전 결과](../server/validation/summary-suite-before-schema.json)를 보존했다. JSON schema로 필드를 제한했고, 제안을 확정으로 바꾸는 표현을 발견해 문장별 발화 의도를 유지하는 지시도 보완했다.

최종 7개는 응답 형식·요약 존재·기대 분류·업무 유형·폴더 조건을 모두 만족했다. 실제 출력도 읽어 취소/미정, 가족 여행 제안, 확정된 배포와 QA 공유 제안, 견적 요청, 아이디어 제안의 구분을 확인했다. 7/7은 이 작은 평가의 조건 충족이며 일반 요약 정확도 수치가 아니다.

## iPhone 시뮬레이터 직접 확인

- 한국어/English → 가운데 버튼 → English/한국어, 설정 창 없이 즉시 교환.
- 입력 언어 버튼 → 일본어 한 번 선택 → 시트 닫힘과 즉시 반영.
- 보조 입력의 검증용 초안 `2026`을 유지하면서 언어 교환, 입력 언어 표시도 갱신. 검증 후 미전송 초안을 지웠고 새 대화는 생성하지 않았다.
- 화자 입력 메뉴 없음. 톱니바퀴 아이콘과 언어별 독립 접근성 버튼 확인.
- 화면 모드 선택의 즉시 변경과 다크 상태 재실행 복원. 최종 아이콘식 화면에서 기기→라이트→다크→기기 순환 확인.
- 설정에서 언어/서버 폼이 사라짐. Debug 더보기에서만 개발자 연결 시트 확인. 업무 폴더에서 기존 apollo 폴더 확인.
- 기존 기록 상세의 요약 탭·직접 작성 폼·2000자 검사 표시, 제목/분류 더보기에 재생성 항목 없음 확인. 기존 기록은 수정하지 않았다.
- 개발 토큰 미입력 오류의 일시 알림과 닫기 버튼이 자동으로 사라지고 항목별 오류는 남는 것을 확인.
- 기존 대화 4개 유지. 기기 설정 모드·대화 시작 화면으로 복원.

Android 최종 APK 설치·실행은 확인했다. 이번 수정의 전체 클릭 흐름은 iPhone에서 확인했으며 Android 직접 조작 전체를 완료했다고 주장하지 않는다. VoiceOver/TalkBack 청취, 실제 휴대전화, 음성 자동 감지, 외부 배포 인증은 미검증/보류다.
