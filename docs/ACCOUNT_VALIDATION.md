# 자동 연결·회원 인증 검증

2026-10-18. 이번 구현은 회원가입/로그인만 제공하며 게스트는 없다. 서버는 현재 MacBook이다. 후속 중앙 DB 전환은 별도의 설계·승인 범위다.

## 확인 결과

| 검증 | 결과 |
| --- | --- |
| Node 서버 회귀 | 44개 통과 (기존 38 + 인증 6) |
| Android host | 48개 통과 |
| iOS simulator 공통 테스트 | 48개 통과 |
| Android 에뮬레이터 instrumented | 47개 통과; 실제 Keystore 암호화·재열기·변조 거부·삭제 포함 |
| Android Debug / Release APK | 빌드 성공 |
| iOS Debug 시뮬레이터 앱 | 로컬 서명 빌드 성공 |
| 배포 주소 생성 | 예시 HTTPS origin 적용 확인, HTTP origin 빌드 거부 확인; 최종 기본값은 빈 주소로 복원 |
| 색상·대비 검사 | 30쌍 통과, 최소 대비 5.62 |

플랫폼별 공통 테스트는 서로 중복되므로 독립 기능 검증 수를 합산하지 않는다. 결과 수치는 `validation/account-tests.json`에 기록했다.

서버 검증은 회원가입·로그인·세션 조회·로그아웃, 기존 공용 토큰 우회 거부, 게스트 경로 없음, 유효성·중복·본문 크기 검사, 세션 만료, 회원별 요청 제한, DB 재열기 후 세션 유지·폐기, 원문 비밀번호·Bearer 미저장, 위조 프록시 헤더로 인증 제한 우회 불가, 활성 로그인 5개 제한을 포함한다. 모델 응답은 이 테스트에서 대체 응답을 사용했다.

공통 클라이언트 검증은 세션만 저장(비밀번호 제외), 앱 재실행 복원, 로그인 전 네트워크 호출 방지, 서버 origin 변경·기한 만료 시 기존 토큰 전송 방지, 로그아웃 후 삭제, 이전 세션의 늦은 401 차단, 안전한 오류 문구, 보안 저장 실패 시 새 세션 폐기, 로그인/로그아웃 동시 실행 순서를 포함한다.

## 네이티브 UI

iPhone 17 Pro 시뮬레이터에서 임시 검증 전용 SQLite DB와 가상 계정을 사용했다. 사용자 계정이나 실제 대화는 인증 검증에 전송하지 않았다.

- 설정 → 회원가입 → 회원 상태 표시 확인. 주소·공용 토큰 입력 없이 Mac API 도달.
- 앱 종료·재실행 후 Keychain 로그인 복원 확인.
- 로그아웃 확인창과 서버 세션 폐기, 앱 재실행 후 로그인 해제 확인. 검증 DB의 잔여 활성 세션 0개.
- 기존 대화 4개와 업무 폴더 1개 유지. 검증 과정에서 대화 생성·삭제 없음.
- 최종 화면 모드는 **기기 설정·라이트·다크 아이콘 세 개 가로 나열**. 각 모드 직접 선택, 선택 강조, 다크 선택 후 재실행 복원 확인. 최종 기기 설정 모드로 복원.

초기 unsigned 시뮬레이터 빌드에서는 Keychain 읽기가 실패했다. 로컬 임시 서명한 Xcode 빌드에서 저장·재실행 복원·삭제를 확인했다. 서명 없는 빌드 성공을 Keychain 동작 성공으로 간주하지 않는다.

Android 에뮬레이터는 저장소 instrumented 검증을 완료했으며 전체 로그인 화면 클릭 흐름을 확인했다고 주장하지 않는다. 실물 휴대전화·실제 음성·스크린리더 청취는 계속 보류다.

## 현재 실행과 한계

검증용 API를 종료한 뒤, 실제 회원 설정으로 Mac API(127.0.0.1:8787)와 기존 Ollama(127.0.0.1:11435)를 실행했다. API의 users 인증 상태와 기존 모델 목록을 확인했다. 이번 인증 변경 검증에서 실제 모델 추론 품질 평가는 반복하지 않았다.

고정 HTTPS 주소·공개 터널·스토어 배포는 미실행이며 Release에 실제 운영 주소를 넣지 않았다. 로그인 없이 기록을 열고 편집하는 현재 동작, 기기 단위 저장·계정별 미분리, 비밀번호 재설정 미지원, 오프라인 로그아웃 제한은 `ACCOUNT_SERVER.md`에 명시했다. 후속 사용자 요청인 모든 데이터의 중앙 DB 저장은 이 구현에 포함되었다고 주장하지 않는다.
