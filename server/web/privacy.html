음성과 AI

음성은 인식 처리에 사용하고 임시 파일을 정리합니다. 원음을 영구 기록으로 저장하지 않습니다. 번역·요약·인식은 운영자의 Mac에서 수행하며 유료 클라우드 AI로 자동 전송하지 않습니다. 위치·연락처·광고 식별자를 수집하지 않습니다.

삭제와 보존

계정 삭제는 서버의 사용자 기록과 세션을 즉시 제거합니다. 백업은 생성 후 30일 정책으로 정리하며 서버가 꺼져 있으면 다음 실행 때 처리합니다. 삭제 영수증에는 계정 ID·아이디·세션의 해시와 삭제 시각만 남겨 오래된 백업으로 계정이 되살아나는 것을 막습니다. 삭제 영수증의 원문 데이터나 비밀번호는 보관하지 않습니다.

앱을 다시 연결하면 확인 가능한 삭제 세션의 전송 대기 데이터를 정리합니다. 로그아웃·일반 인증 만료만으로 대기 데이터를 삭제하지 않습니다. 사용자가 별도로 보관한 파일이나 명시적으로 가져오지 않은 과거 기기 기록은 이 서버 계정에 속한다고 임의로 판단하지 않습니다.
